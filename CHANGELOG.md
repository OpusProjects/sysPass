# Changelog

All notable changes to this project are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the

## [Unreleased]

### Security

- Require app-admin role to grant admin flags and profile permissions — closes a privilege-escalation path where any authenticated user could self-elevate (#416)
- Key brute-force login tracking on `REMOTE_ADDR` instead of the spoofable `X-Forwarded-For` header (#409)
- Scope notification view, check, and delete to the owner — fix IDOR (#407)
- Enforce per-account authorisation on account file and account mutation endpoints — close file and account IDOR (#388, #389)
- Enforce ACL server-side on plugin enable/disable/reset and event-log clear endpoints (#403)
- Regenerate session ID on login and re-key the session vault to prevent session fixation (#385, #395)
- Fix stored XSS in public-link and user-profile views (#384), DataGrid cells (#318), account search rows (#287, #319, #320), uploaded file name and type (#356), and custom-field help text (#355)
- Harden installer pre-auth path against two injection vectors (#360)
- Restrict backup archives and intermediate dumps to the owner (#412)
- Make master-password rotation atomic — abort on partial re-key instead of committing corrupt state (#410)
- Reject the unauthenticated upgrade endpoint when no valid key is configured (#411)
- Abort encrypted import instead of silently corrupting passwords without a valid master password (#405)
- Enforce MIME and size validation on API file upload; use the authenticated user in `AccountAcl` (#413)
- Don't fall back to the service-account password on an empty LDAP bind — prevents unintended authentication (#414)
- Restrict `unserialize` allowed classes in `Serde::deserialize` (#300)
- Add `HttpOnly`, `Secure`, and `SameSite=Strict` flags to the `SYSPASS_UUID` cookie (#305)
- Prioritise server-side MIME check over client-supplied `Content-Type` on file uploads (#306)
- Increase PBKDF2 iterations from 5,000 to 100,000 (#307)
- Increase RSA key size from 1,024 to 2,048 bits (#304)
- Replace `uniqid()` with `random_bytes()` for public-link hash generation (#301)
- Use timing-safe `hash_equals()` for legacy password hash comparison (#288)
- Fix rate-limiting bypass caused by an erroneous `LIMIT 1` in the Track query (#297)
- Use CSPRNG for backup/export download hashes; stop logging the CSRF token (#387)
- Bind the CSRF token to the session instead of deriving it from request headers, and require it on every signed-in request (#586, #1005)
- Authorise the caller against the account in the REST API — any token could previously read, edit or delete any account (#572)
- Keep private accounts private however reached: account manager, public links, history restore, API, access requests (#764, #765, #872, #913, #928, #944)
- Hold account privacy and sharing flags to the permissions that gate them, web and API; a restore cannot reassign an account (#793, #875, #886, #929, #943)
- Stop the API handing out users' credential material, a token's secrets on delete, and other users' tokens in search (#688, #701, #1001)
- Refuse issuing an auth token for a user the caller cannot manage, and a user manager acting on an administrator (#997, #1000)
- Stop a caller granting a profile, permissions or preset beyond their own; require the matching permission for presets (#769, #871, #874, #914, #940)
- Scope notification edit and delete to the owner, and keep the broadcast flags to administrators (#695, #770, #841)
- Require an administrator for the release and notices status checks (#808)
- Enforce the profile's Files permission on every file operation, and require view-password permission to create or refresh a public link (#941, #991, #999)
- Serve only files inside the application's resource directories (#696)
- Stop sending the stack trace to the browser, and strip argument values from stack traces in logs (#716, #924)
- Make timing and replies identical for known and unknown users (login, LDAP, legacy hash, password reset, public link) (#725, #794, #838, #868, #898)
- Count wrong passwords, wrong API tokens, in-flight attempts and every temporary master password guess towards their limits (#742, #767, #814, #942)
- Make a public link's view limit atomic, and take the API token from the `Authorization` header only (#732, #813)
- Escape text where rendered, not on input; fix XSS in messages, mails, file names, data attributes, toasts and `javascript:` URLs (#758, #759, #760, #869, #927, #939)
- Stop an attachment name from rewriting its download header, and stop a declared MIME type overriding the detected one (#588, #755)
- Mask encrypted custom fields whatever their type, for API callers too, and never save a masked value over the real secret (#830, #861, #895)
- Refuse demo-mode operations on the API, backups, exports, status and master password rotation, and temporary master passwords (#831, #835, #846, #992)
- Do not let a session outlive its account: re-check the user, profile and group on every request, and the token user's profile on every API call (#834, #947, #1004)
- Rotate session identifiers for signed-in users (wire the session key service) (#804)
- Make "Force HTTPS" actually stop the plaintext response (#876)
- Restrict backups, exports, archives and the config cache to their owner from the moment they exist (#840, #883, #903)
- Show a temporary master password once; keep master passwords off the command line; enforce their minimum length everywhere (#887, #906, #946)
- Do not build reset links from a caller-chosen header, and spend outstanding reset links when a password changes (#915, #916)
- Generate passwords from the platform CSPRNG; fail closed instead of writing plaintext session data on an encrypt error (#446, #870)
- Measure bcrypt's key limit in bytes, match IPv6 addresses against networks of their own family, and refuse out-of-range session-timeout networks (#800, #801, #995)
- Keep libxml entity limits on XML import, restrict classes built from cache files, and import only the account fields an export writes (#802, #803, #1009)
- Re-seal a public link's vault when editing the link changes its account, which kept serving the old account's password (#993)
- Fix `DEBUG=false` in the environment enabling debug mode (#443)
- Read API account and token passwords raw so `&`, `<`, `>` and edge whitespace are no longer silently altered (#479, #481)

### Added

- Two-factor sign-in with an authenticator app: turn it on from Settings → Security, with ten single-use recovery codes
- Playwright end-to-end browser test suite covering the install wizard and login flow (#391)
- Full REST API with OpenAPI spec and Swagger UI at `/api/docs/` — replaces the JSON-RPC 2.0 API (#217)
- REST API endpoints for Users, Profiles, Auth Tokens, Custom Fields, Event Log, Notifications, Public Links, and Account Files (#219–#226)
- `docs/ARCHITECTURE.md` — hexagonal layer map, request lifecycle, and DI container rules (#254)
- `docs/TESTING.md` — test suite layout, environment requirements, and authoring guide (#253)
- `CONTRIBUTING.md` — dev setup, PR workflow, and coding conventions (#255)
- npm-managed front-end asset vendoring pipeline (`npm run vendor`) and esbuild CSS minification step (`npm run build:css`) (#392, #402)
- Unit test coverage for `ConfigUtil`, `CustomField`, `ItemPreset`, `ProfileData`, `UserPreferences`, and `FileHandler` (#52, #264–#267)
- REST API: create a user, and create auth tokens that carry a vault (a token password is required) (#693, #833, #839)
- Say when a text is too long, which field and by how much, instead of a generic query error (#809)
- List what actually blocks deleting a user or group, and refuse deleting the account you are signed in as (#684, #810, #888, #889)
- Show an owner and main group when viewing an account's history (#781)
- Configuration: dedicated Security tab, proxy settings inside General, and labelled toggle rows (#439, #440)
- Swagger UI top bar shown at `/api/docs` (#437, #438)
- Report preferences that were not saved, an update that changed nothing, and a history purge's real count (#719, #729, #878)

### Changed

- **Architecture:** restructured to textbook hexagonal layout (`Domain/` → `Application/` → `Infrastructure/`); entry points moved to `public/` (web) and `bin/` (CLI); themes moved from `src/` to `public/` (#55, #234, #241)
- **PHP:** raised minimum to 8.4, added 8.5 support; cleared all 8.4 implicitly-nullable deprecations and 8.5 runtime deprecations (#21, #25, #29, #46)
- **Symfony:** upgraded from 6.4 LTS through 7.4 LTS to 8.1 (#19–#22, #33)
- **PHPUnit** upgraded 11 → 13; **phpmailer** 6 → 7; **phpstan** 1 → 2; **phpseclib** 2 → 3; **monolog** 1 → 3; **guzzlehttp/guzzle** 6 → 7 (#9, #13, #14, #36, #38, #39)
- **jQuery** upgraded to 3.7.1; front-end libraries now npm-managed (#392); **selectize** migrated to the maintained `@selectize/selectize` 0.15.2 fork (#399)
- `SerializedModel` migrated from PHP `serialize` to JSON with dual-read fallback for existing data (#76)
- All Web controllers migrated from the legacy `JsonTrait` / `bool` return pattern to the `ActionResponse` dispatch contract (#60)
- API migrated from JSON-RPC 2.0 to REST; controllers return `ApiResponse` (#75, #217)
- `EventDispatcher` simplified — event name moved into the `Event` object (#80)
- Login page, Configuration panel, and footer status bar redesigned (#233, #238, #240)
- Modernised codebase: replaced `get_class()`, `Closure::fromCallable()`, `call_user_func()`, `strpos() !== false`, and `substr()` suffix checks with PHP 8 equivalents; translated Spanish code comments to English (#23, #259–#284)
- **MariaDB:** bundled and tested image moved from 10.11 to 11.8 LTS (#454)
- **Front-end:** jQuery 4.0.0, toastr and jquery.fileDownload replaced by native code, and vendor libraries built into one esbuild bundle (#428, #468, #470, #498)
- **guzzlehttp/guzzle** upgraded to 8.x (#540)
- Keep the last good export and backup until a new one succeeds, and replace `config.xml` atomically instead of truncating it (#722, #724, #901)
- Keep the previous configuration a save replaces (#905)
- Store text exactly as typed and escape on output; a migration decodes previously stored text (#762)
- Account password-preset expiry is now a ceiling, and password lifetime policy applies on edit and import (#459, #828, #884)
- A fixed preset outranks a default, ties between presets are settled by id, and a preset naming a deleted user no longer breaks saving (#842, #882, #885)
- Page every search over a total order so rows no longer repeat or vanish between pages (#836, #837, #897)
- Hold client, login, profile and group names unique in the database (#806, #825, #826)
- Compiled container is named per module and application version, so upgrades do not serve a stale one (#552, #845)
- Faster account search, listing, export and permission loading (fewer queries per request) (#585, #587, #774, #782)
- Store characters outside the basic plane (#807)

### Fixed

- Numerous `TypeError` crashes from nullable model getters passed to non-nullable parameters across controllers, templates, services, and the API — null-coalesced for PHP 9.0 compatibility (#125–#165, #193–#200)
- Installer: DB connection test, rollback, host parsing, credentials, CLI startup, and password mangling with special characters (#359–#364)
- REST API: master-pass decryption, end-to-end tests, and backup `--path` being ignored (#353, #366, #367)
- Account search: `OR` precedence bypassing the ACL filter, client filter for all users, and tag-only chaining (#278, #317, #332, #333, #370)
- SQL `WHERE` precedence in `AccountSearch`, `User::search`, `checkDuplicatedOnAdd`, and LDAP filter (#289, #317, #332, #349)
- Erroneous `LIMIT 1` in `Track`, `AccountFile::getByAccountId`, `PluginData` delete, and `UserToUserGroup::getById` — each caused silent data truncation or security bypass (#296–#299)
- XML export silently dropping values containing `&` (#354) and import fatal on tagless accounts (#357)
- `BackupFile` SQL export producing invalid `INSERT` statements for null/empty values (#143); database backup corrupting binary values (#361)
- `updateMasterPassById` writing to wrong columns (#295); history rows missing `Account` getters during master-password change (#351, #352)
- `ItemPreset` hash computed from type only — second preset of the same type always hit the UNIQUE key (#350)
- Forced logout ~2 min after login — session vault not re-keyed on ID regeneration (#335)
- `Config → General` never saving Language and Visual Theme (#338); account edits silently wiping the password expiry date (#337)
- `Password::CHARS` alphabet missing the letter `v` (#340)
- `DataGrid` query time always showing 0 s, `getLast()` `TypeError`, and sort constants swapped (#276, #346, #347)
- Reset-email build (`getMailMessage` arity mismatch) — restored the forgot-password flow (#415)
- Public link view answered HTTP 500 and burned a view; created links answer with the hash that is their URL; creating and refreshing links over the API (#565, #566, #610, #820)
- Sharing an account made it unviewable, and the account form discarded the Private flag (#573, #574)
- XML export failed schema validation and dropped passwords; encrypted export importable again; restores and round trips keep accounts readable (#568, #735, #734, #740, #746, #756, #945)
- Master password rotation always aborted on history rows; hash is stored inside the rotation; demo no longer half-rotates (#571, #817)
- Upgrade detection, key generation and the upgrade itself restored; an interrupted upgrade resumes; migrations apply as one statement (#495, #761, #822, #917)
- API and CLI entry points dead on a shared compiled container, and an unbootable app after the hexagonal move (#530, #552, #865)
- Saving LDAP settings made every LDAP login fatal; LDAP directory answers without a dn no longer crash; full LDAP server strings are parsed (#487, #711, #798)
- Editing an account with custom fields fataled; clearing one custom field deleted the others; moving a field between modules works; missing definitions no longer fatal (#492, #569, #687, #862, #864)
- Custom field types seed restored, and an export password of "0" is a password (#570, #863)
- Notification broadcast, group/profile/user managers, favourites, version restore and "Remove Account" now work (#751, #752, #848)
- Attachments: binary files in API responses, optional extension, thumbnail height, failed upload reported as success (#563, #644, #670, #811)
- Replace raw SQL errors with translated messages; answer wrong parameter types, empty or blank required values with 400, not 500 (#482, #560, #796, #832, #938, #994)
- Refusals on category, client and token endpoints answer as errors, not 500s, and duplicate names are detected again (#1002, #1007)
- Partial writes no longer reported as done: stale batch deletes, account edits matching no row, link deletes, updates matching nothing (#849, #850, #899, #900, #996)
- Abort an import when an account cannot be written, skip blank CSV rows, KeePass gaps and default CSV delimiter; an upload must arrive (#486, #562, #564, #739, #1003)
- Search for `0` returns accounts matching it, negative page sizes are empty pages, and password history is looked up by its own id (#567, #717, #827)
- Tell PHP the configured session lifetime while it will still listen, and make the session accessors return what they hold (#718, #720)
- Infinite redirect on the maintenance page, error page sent twice, event log line breaks (#478, #637, #771)
- Log write failures no longer fail the request; corrupt cache files are rebuilt; nested transactions do not commit the outer one (#881, #925, #937)
- Installer: rollback drops only the database it created; a socket selects the environment's database; `.env.example` matches the code (#791, #799, #926)
- Mail a group's member once however many groups they are in, and report the web server without assuming `SERVER_SOFTWARE` (#775, #824)
- No longer fatal: archiving a whole directory, an unknown auth-token id, a partial mail check, empty bulk-edit selections, a missing notification text or account id (#546-#551, #912)
- Find the export to download whichever door made it, and answer a missing backup or export without a server error (#1008)
- Refuse a change that would leave no active application administrator; an API user edit keeps the flags it does not send (#1006)
- Fix `mb_ucfirst()`, AppLock creation, CLI variables from `.env`, and API help matching what the controllers read (#460, #480, #491, #754)
